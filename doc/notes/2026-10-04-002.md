### 📊 Objectif

POST /api/auth/magic-link { email }
- crée l'identité magic-link (secret aléatoire et expiration) et envoie un lien vers la SPA, par exemple https://zealot.fr/?magic=....

POST /api/auth/magic-link/verify { token } 
- supprime l'identité (usage unique), vérifie l'expiration et que le compte est actif, puis renvoie un access token comme login().

POST /api/auth/password (avec token) { new_password }
- permet de changer le mot de passe après connexion.

Cela réutilise **UserIdentityModel** et la logique de **MagicLinkController**, sans toucher aux pages natives.

### Ce qui a été ajouté

|Route|Rôle|
|---|---|
|`POST /api/auth/magic-link` `{email}`|crée l'identité `magic-link` (usage unique) et envoie un lien vers la SPA. Réponse identique que le compte existe ou non.|
|`POST /api/auth/magic-link/verify` `{token}`|échange le jeton contre un token API (comme `login`).|
|`POST /api/auth/password` `{new_password, current_password?}`|changement de mot de passe, protégé par Bearer.|

Quelques choix à connaître :

- **Le lien est de la forme `https://zealot.fr/#magic=TOKEN`.** Le fragment n'est jamais envoyé au serveur, donc le jeton n'apparaît ni dans les logs ni dans le `Referer`. Si votre SPA n'est pas à la racine, changez la constante `SPA_PATH`.
- **L'identité est supprimée avant toute autre vérification** : un lien ne sert qu'une fois, même expiré.
- **Le token délivré s'appelle `magic-link`.** Pendant 15 minutes, il permet de changer le mot de passe sans l'ancien, ce qui est le cas d'usage « mot de passe oublié ». Sinon, `current_password` est obligatoire et vérifié.
- **Après un changement, tous les tokens sont révoqués** (autres appareils compris) et un nouveau token est renvoyé. Le front le remplace.
- **La robustesse du mot de passe suit `Config\Auth::$passwordValidators`**, pas votre regex du front. Les deux peuvent diverger.

const PWD_COMPLEXITY = /^(?=.*[A-Z])(?=.*\d)(?=.*[^A-Za-z0-9]).{8,}$/

function renderPasswordForm() {
    const hint = authStore.viaMagic
        ? '<p class="panel-hint"><em>Connexion par lien : définissez un nouveau mot de passe ci-dessous.</em></p>'
        : ''
    const current = authStore.viaMagic
        ? ''
        : '<input type="password" name="current_password" placeholder="Mot de passe actuel" autocomplete="current-password">'
    return `
        <hr>
        <h4>Changer le mot de passe</h4>
        ${hint}
        <div class="auth-form auth-password-form">
            ${current}
            <input type="password" name="new_password"     placeholder="Nouveau mot de passe" autocomplete="new-password">
            <input type="password" name="confirm_password" placeholder="Confirmer"            autocomplete="new-password">
            <button type="button" class="auth-pwd-submit">Enregistrer</button>
            <p id="pwd-msg" class="auth-error" hidden></p>
        </div>`
}

function setPasswordMessage(text, isError) {
    const p = document.querySelector('#pwd-msg')
    if (!p) return
    p.textContent = text
    p.className   = isError ? 'auth-error' : 'auth-success'
    p.hidden      = false
}

function bindPasswordForm(body) {
    body.querySelector('.auth-pwd-submit')?.addEventListener('click', () => {
        const val = (n) => body.querySelector(`[name="${n}"]`)?.value ?? ''
        const p1 = val('new_password')

        if (p1 !== val('confirm_password')) return setPasswordMessage('Les mots de passe ne correspondent pas.', true)
        if (!PWD_COMPLEXITY.test(p1))       return setPasswordMessage('Mot de passe trop faible (min. 8 car., 1 majuscule, 1 chiffre, 1 caractère spécial).', true)

        bus.publish('auth:password:change', { newPassword: p1, currentPassword: val('current_password') })
    })
}
